Para executar o programa no VS Code, podes utilizar os comandos no terminal ou a própria interface do editor:

Opção 1: Via Terminal (Direto no Java 11+)

    Abre o terminal no VS Code utilizando o atalho Ctrl + ' (ou Cmd + ' no Mac).

    Executa o ficheiro diretamente com o comando:

    java Main.java

    (ou java Olimpiadas.java caso estejas a utilizar esse ficheiro)

Opção 2: Compilação Tradicional (javac)

    Compila o código fonte:


    javac Main.java

    Executa a classe gerada

    java Main

    Opção 3: Pela Interface do VS Code (Sem Comandos)

    Garante que tens a extensão Extension Pack for Java instalada no VS Code.

    Abre o ficheiro Main.java.

    Clica no texto Run que aparece automaticamente por cima da linha public static void main(String[] args) ou clica no botão de execução (▶) no canto superior direito da janela.
